# Asset attribution

Every non-code asset in this repository (images, icons, fonts, example models, test fixtures) is
listed here with its author, source and licence. `cargo xtask assets` (part of `cargo xtask ci`)
fails if an asset file is missing from this table.

**Policy (mandatory):**

- Tenon contains **no Autodesk iconography, images, artwork, fonts, sounds, templates or
  documentation text**, and no assets from any other commercial CAD product. Every asset is
  original work by Tenon contributors or third-party material under an open licence (OSI open
  source, public domain / CC0, or a Creative Commons licence that allows redistribution).
- Screenshots of other vendors' software are never committed, including reference screenshots
  used to study layout.
- UI icons are drawn in code; there are no icon files to list.
- Example and fixture models are generated by Tenon itself (the generating command is noted).

Generated-in-code assets are original and have no file to list:
- the UI icon set (`crates/ui/src/icons.rs`, from M0's layout shell onward).

Standard sizes and physical constants held in code:
- the ISO metric coarse thread series, M1 to M64 (`crates/model/src/threads.rs`): 21 pairs of
  nominal diameter and pitch, the first-choice coarse sizes of ISO 261, with the proportions of
  the basic 60 degree profile (ISO 68-1). These are facts of the standard, typed in; no dataset,
  table or text of the standard is copied (DEC-038).
- the material library (`crates/model/src/materials.rs`): 22 common workshop materials, each
  with a typical density in g/cm^3 and a display colour. The densities are rounded handbook
  values, facts typed in one by one; the names are generic and the colours were chosen for
  Tenon. No material database, library file or vendor data is copied (DEC-043). A density is a
  typical figure, not a specification: a part's own density can be typed over it.
- the standard parts library (`crates/model/src/library.rs`, DEC-049): the dimensions of ISO
  metric fasteners M3 to M20 (hexagon across flats and head height of ISO 4017, head and socket
  sizes of ISO 4762, nut height of ISO 4032, the normal series of plain washers of ISO 7089,
  with the coarse pitches of ISO 261), the boundary dimensions (bore, outside diameter, width)
  of seventeen deep groove ball bearings as ISO 15 gives them, and common sizes of tube, angle
  and flat bar. These are facts of the standards, typed in one by one; no dataset, catalogue,
  table, drawing or text of a standard or of a supplier is copied. The lengths offered for each
  screw are a choice of preferred lengths made for Tenon. The T-slot profile is Tenon's own
  simplified section and no maker's design. The parts are built from these numbers by Tenon's
  own commands, with the simplifications each family's description states.
