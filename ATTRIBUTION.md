# Asset attribution

Every non-code asset in this repository (images, icons, fonts, example models, test fixtures) is
listed here with its author, source and licence. `cargo xtask assets` (part of `cargo xtask ci`)
fails if an asset file is missing from this table.

**Policy (mandatory):**

- Tenon contains **no Autodesk iconography, images, artwork, fonts, sounds, templates or
  documentation text**, and no assets from any other commercial CAD product. Every asset is
  original work by Tenon contributors or third-party material under an open licence (OSI open
  source, public domain / CC0, or a Creative Commons licence that allows redistribution).
- Screenshots of other vendors' software are never committed, including reference screenshots
  used to study layout.
- UI icons are drawn in code; there are no icon files to list.
- Example and fixture models are generated by Tenon itself (the generating command is noted).

Generated-in-code assets are original and have no file to list:
- the UI icon set (`crates/ui/src/icons.rs`, from M0's layout shell onward).
